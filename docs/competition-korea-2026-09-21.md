## 2. 경쟁 지형 (6개 군)
### A. 단일 모델 공식 앱 — 챗GPT·제미나이·클로드·그록·퍼플렉시티
- 각 월 $20 안팎(≈₩27,000). 우리 서비스의 **원재료이자 경쟁자**.
- 약점: 서로 비교할 수 없고, 답이 맞는지 다른 모델에 물으려면 복붙해야 함. 이 마찰이 우리의 존재 이유.

### B. 국내 집계·포털형 — 뤼튼, 에이닷, 클로바X
- **뤼튼**: 2023년 말 전면 무료화. GPT 계열을 포함한 여러 모델을 무료 제공, 수익은 광고·캐릭터 챗(월 4,900원·19,900원, 토큰 판매 1,900~199,900원). 유료 프리미엄(과거 34,900원 계획)은 사실상 접음.
- **에이닷**: SKT가 GPT·클로드·제미나이 등을 한 앱에서 무료로 고르게 함. 통신사 번들이라 원가 부담을 감수.
- 시사점: **"여러 모델을 쓸 수 있다" 자체는 이미 무료**다. 모델 접근권으로는 돈을 받을 수 없고, 비교·검증·기록 워크플로로만 받을 수 있다.

### D. 국내 B2B 멀티 LLM — WindyFlo 등
- 20개 이상 LLM을 업무별로 고르는 기업용. 개인 대상이 아니고 가격대·판매 방식이 다름. 직접 경쟁은 아니나, 우리가 "팀 기능"으로 확장할 때 부딪힘.

### E. 정보·벤치마크 사이트 — 모켓, 캐럿, 드롭샷
- 벤치마크 기반 순위·요금 비교. 사용자 유입 채널이지 경쟁자는 아님. 제휴·콘텐츠 마케팅 대상.

### F. 참조 서비스 — Omni AI Workspace (RRL LAB)
- "ChatGPT · Claude · Gemini 동시 비교" 데스크톱. 페이지가 JS 렌더링이라 기능·가격은 확인 못 함. 콘셉트상 jilseo와 같은 "구독 계정 화면 연동" 방식으로 추정되며, 같은 약관 회색지대에 있음. 이 방식으로는 일반 사용자 유료화가 어렵다는 것이 우리 결론이므로, 이 서비스가 어떻게 수익화하는지(있다면)만 추적하면 됨.

## 3. 가격 앵커
| 기준 | 금액 |
|---|---|
| 단일 공식 앱 1개 | ≈₩27,000/월 |
| 3개 공식 앱 | ≈₩81,000/월 |
| Genspark Plus | ≈₩27,600/월 |
| 뤼튼·에이닷 | 무료 |
| 캐릭터 챗(국내 소비자 감각) | 4,900~19,900원 |
| 우리 제안 | Basic 9,900 / Pro 24,900 / Max 49,900 |

- Pro 24,900원은 "공식 앱 하나 값으로 다섯 모델 비교 + 검증"이라는 메시지가 성립.
- Basic 9,900원은 국내 소비자의 AI 지불 감각(4,900~19,900) 안에 있음.
- 무료 티어는 뤼튼·에이닷과 정면 경쟁하면 진다. 무료는 "체험"으로만 두고, 비교·검증 결과의 **보관·검색·내보내기**를 유료 경계로 삼는다.

## 4. 시사점 — 어디서 이길 수 있나
1. **모델 접근이 아니라 판정을 판다.** 뤼튼·에이닷이 무료로 주는 것(모델 선택)과 겹치지 않게, "생성 → 검증 1·2 → 판정"을 첫 화면의 기본 흐름으로.
2. **투명한 검증 vs Genspark의 합성.** Genspark는 여러 답을 섞어 하나로 준다. 사실 확인이 중요한 사용자(리서치·법무·교육·개발)는 "어느 모델이 무엇을 지적했는지"를 보고 싶어 한다. 이 차이를 마케팅 문장으로.
3. **기록이 자산이 되게.** 비교 기록·판정·평가를 검색·태그·Obsidian/노션 내보내기까지 — 추천 의향이 높은 노트북LM류 수요와 맞닿음.
4. **개인 성적표.** "내 질문 유형별로 어떤 모델이 잘했는지" 통계는 어느 경쟁자도 안 한다. 라우팅 제안의 근거이자 잠금(lock-in) 효과.
5. **한국어 프롬프트·검증 템플릿 라이브러리.** 해외 서비스가 약한 부분.

## 5. 위험
- **대형 사업자의 번들화**: 에이닷이 이미 멀티 LLM을 무료로 줬듯, 네이버·카카오가 "비교" 기능까지 넣을 수 있음. 방어는 깊이(검증·기록·성적표)와 속도.
- **모델 제공사 자체 기능**: 챗GPT·제미나이가 "다른 모델과 비교" 기능을 넣을 가능성은 낮지만(자사 모델 노출 이해관계), 퍼플렉시티는 이미 모델 선택 UI가 있음.
- **원가 변동**: 토큰 단가는 내려가는 추세라 유리하지만, 프리미엄 모델 신제품 출시 직후는 비쌈 → 요금제는 포인트 체계로 흡수.
- **약관**: API 기반이면 문제 없음. 단 "재판매" 조건과 브랜드 사용(모델명 표기) 정책 확인.

## 6. 초기 진입 제안
- 타깃 1순위: 사실 확인이 중요한 지식노동자(리서치·기획·법무·교육), 2순위: 개발자(코드 리뷰를 두 모델에 검증).
- 채널: gpters 같은 AI 실무 커뮤니티, 브런치·유튜브 AI 활용 콘텐츠, 모켓·캐럿 같은 비교 사이트 제휴, 검증 결과 공유 링크(바이럴).
- 메시지: "AI 답변, 다른 AI가 검증합니다" / "공식 앱 하나 값으로 다섯 모델".
- 베타 지표: 검증 파이프라인 사용 비율, 유료 전환율, 포인트 소진율, 기록 재방문율.
