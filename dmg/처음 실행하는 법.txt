질서 疾書 — 처음 실행하는 법
=============================

이 앱은 개인용으로 ad-hoc 서명만 되어 있고 Apple 공증을 받지 않았습니다.
그래서 다른 맥에서 처음 열 때 macOS가 막을 수 있습니다. 아래 순서대로 하세요.

1. 앱을 Applications 폴더로 드래그합니다.

2. 처음 열 때 "손상되었기 때문에 열 수 없습니다" 또는 "확인되지 않은 개발자" 경고가 뜨면
   다음 중 하나를 합니다.
   - Applications에서 jilseo 앱을 우클릭 → 열기 → 열기
   - 또는 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"
   - 또는 터미널에서:  xattr -cr /Applications/jilseo.app

3. 앱이 열리면 각 패널에서 ChatGPT, Claude, Gemini 등에 직접 로그인합니다.
   - 앱은 비밀번호·쿠키를 다루지 않습니다. 로그인은 웹뷰 안에서 서비스 사이트가 처리합니다.
   - 패스키(지문·Face ID)는 앱 안에서 쓸 수 없습니다. 로그인 화면에서
     "다른 방법 시도 → 비밀번호"를 고르세요. Google 계정에 "가능하면 비밀번호 건너뛰기"가
     켜져 있으면 끄셔야 비밀번호 선택지가 나옵니다.
   - Google 로그인이 팝업 창으로 열리는 서비스가 있습니다. 끝난 뒤 닫히지 않으면 직접 닫으세요.

4. 하단 입력창에 질문을 쓰고 "보내기"(⌘⏎)를 누르면 모든 패널에 동시에 전송됩니다.

5. 창이 가려지거나 화면이 잠겨도 전송과 응답 수집은 계속됩니다. Mac이 절전에 들어가면 멈추니
   긴 응답을 기다릴 때는 절전만 피하세요.

6. 파일을 첨부해 보내면 ChatGPT는 응답을 받은 뒤 자동으로 새 채팅으로 이동합니다
   (파일이 붙은 대화방에서는 이후 답변이 생성되지 않는 경우가 있어서). 설정에서 끌 수 있습니다.

문제가 생기면
- 전송이 실패하는 서비스가 있으면 사이트가 개편된 것입니다. 앱 헤더의 "셀렉터 JSON 폴더"에서
  해당 서비스의 JSON을 고치고 앱을 재시작하면 반영됩니다.
- 앱 데이터 위치: ~/Library/Application Support/jilseo/

요구 사항: macOS 14 (Sonoma) 이상
