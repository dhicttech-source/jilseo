## 6. 운영 규칙
- 포인트 차감은 **응답 완료 후 실제 토큰**으로. 사전 예약(예상 P) → 완료 후 정산.
- 프롬프트 캐싱(시스템 프롬프트·검증 템플릿)으로 입력 원가 30~50% 절감 가능 → 위 계산에 미반영(안전 여유).
- 배치 API(50% 할인)는 실시간 서비스라 미적용. 야간 대량 작업 기능을 넣는다면 그때 활용.
- 단가·환율은 분기마다 재계산. 모델 교체(예: 표준 등급의 기본 모델)는 포인트 체계를 유지한 채 내부 매핑만 바꾼다.

## 7. 제안
1. 출시는 Free + Basic + Pro 3단계로 시작. Max는 베타 데이터로 헤비 유저 분포를 본 뒤 결정.
2. 검증 파이프라인을 Basic부터 열어 "다른 서비스엔 없는 기능"으로 전환 동기를 만든다.
3. 첫 3개월은 Pro를 ₩19,900 프로모션가로, 연간 결제 2개월 할인.
4. 베타에서 사용률(포인트 소진율)과 프리미엄 비중을 실측해 Basic 포인트를 400~600 사이에서 조정.
